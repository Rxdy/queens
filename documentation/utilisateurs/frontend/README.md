# Interface — Documentation Utilisateur

Queens Game Solveur — application web pour résoudre le jeu Queens de LinkedIn.

---

## Fonctionnalités

| Section | Description |
|---|---|
| [Grille](./grille.md) | Peindre les zones de couleur, visualiser les solutions |
| [Brouillons](./brouillons.md) | Sauvegarder et naviguer entre plusieurs configurations |
| [Import](./import.md) | Charger une grille par texte ou capture d'écran |
| [Benchmark & Stats](./benchmark.md) | Comparer TRM vs Baseline, graphique de performance |
| [Raccourcis clavier](./raccourcis.md) | Toutes les actions disponibles au clavier |

---

## Vues principales

L'application a trois onglets accessibles en haut de page :

| Onglet | Raccourci | Description |
|---|---|---|
| **Jeu** | — | Grille interactive de peinture et résolution |
| **Historique** | — | Liste des résolutions de la session |
| **Statistiques** | — | Graphique TRM vs Baseline |
